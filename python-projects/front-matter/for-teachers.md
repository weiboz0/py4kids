# For Teachers

This Teacher's Edition contains everything in the Student Book, plus two additions for each unit.

- **Teacher notes** open every unit: learning goals, a 60–90 minute pacing plan for each lesson (with a
  "60-minute cut" when time is short), the project hook, common mistakes, discussion prompts, and
  differentiation for students who need support or extension.
- **Answer keys** follow every exercise set, the end-of-unit Challenges, every checkpoint, and both
  projects. Each answer shows a complete solution and, where the exercise has one, the **real program**
  that reads its input with `input()`, together with a sample input and the expected output.

Every program and every printed output in this book is run automatically before the book is built, so the
code and the results on the page always agree.

The notebooks that this book is made from are the classroom materials: students can run each lesson in
Jupyter, where the same expected outputs are shown under each cell.
Turtle drawings are the exception: they appear only in the book, because a turtle program draws in its
own window when a student runs it.
