# Using This Answer Key

This book gives worked answers to the odd-numbered exercises in every unit.
The answers are grouped by unit, in the same order as the exercises.

## Try first, compare after

Work on each exercise in your exercises notebook before you open this book.
Run your program with every worked sample and fix what does not match.
If you get stuck, read just enough of the answer to spot your next step, close the book, and finish the program yourself.
When you are done, compare your program with the answer and ask why any differences matter.
Copying an answer teaches your eyes, not your hands; writing the program yourself is what builds the skill.

## A different program can be right

Most problems have many correct programs.
Your program is correct when it follows what the exercise asks and reproduces every worked sample exactly: the same lines, spaces, numbers, and punctuation.
Your variable names, the order of some steps, or the way you build a result may differ from the answer shown here.
That is fine.
Still read the printed answer, because a second way to solve a problem is worth learning.

## Reading an answer

A line such as Check: `add_tax(10)` → `11` means that when your code runs the call `add_tax(10)`, the result should be `11`.
Run the call yourself, for example with `print(add_tax(10))`, and compare what you get with the value after the arrow.
When the value is `True`, the whole expression before the arrow should come out true.

Many exercises are worked with fixed sample values first.
The answer then shows **The real program**, which reads its values with `input()` while it runs.
Run it, type the sample inputs, and check that the output matches the sample.
For a turtle exercise, a drawing for the sample input follows the real program.

When an exercise asks for a `.py` file, the answer shows the whole file with its name above it.

## Why only the odd-numbered exercises

The even-numbered exercises are for checking yourself.
Each one has worked samples, so you can tell on your own whether your program is right: if it matches every sample exactly, you have solved it.
Use the odd-numbered answers to learn a method, then prove you can use it on the even-numbered exercises.

The four checkpoints, the two projects and the end-of-unit Challenges are not in this book for the same reason.
They measure what you can do on your own, and their worked samples tell you whether you succeeded.
