# About This Book

You can learn Python by building things.
Every unit in this book starts with something to make: a story machine, a number-guessing game, turtle art, a quiz show, secret codes, a word game, a virtual pet.
You learn each new idea at the moment your project needs it.
You need no programming experience.
If you can follow a recipe and use ordinary middle school math, you are ready.

Read the lesson, run its examples, and then build the exercises yourself.
When a program surprises you, change one part and run it again to find out why.
Along the way, four checkpoints let you prove what you can do, and two projects let you design and build a game of your own.
You can study at your own pace, and return to an earlier page whenever you need to.

You need a computer and the course files.
Begin with Unit 0, Getting Set Up, to install the tools and run your first program.
