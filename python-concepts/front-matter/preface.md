# About This Book

You can learn Python from the beginning, one idea at a time.
This book starts with a small program that prints words and grows toward drawings, games, saved files, and objects that remember their own data.
You need no programming experience.
If you can follow a recipe and use ordinary middle school math, you are ready.

Each unit opens with something to make or a problem to solve.
Read the lesson, run its examples, and then try the exercises yourself.
When a program surprises you, change one part and run it again to find out why.
Take breaks, return to an earlier page when you need to, and use the worked samples to check your progress.
You can study at your own pace.

You need a computer and the course files.
Begin with Unit 0, Getting Set Up, to install the tools and run your first program.
