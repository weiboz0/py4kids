# About This Book

This book is for students who already write Python programs and want to solve contest problems with them.
It prepares you for the Bronze division of the USA Computing Olympiad, where each problem gives you an input, a precise rule, and limits on size, and asks for exactly one correct output.

Every unit starts with a problem worth solving, then teaches the technique that cracks it: reading input carefully, counting how much work a program does, sorting, searching every possibility, simulating, prefix sums, recursion, stacks and queues, number theory, trees, grids and graphs, and two pointers.
Each unit's exercises move from warm-ups to full contest problems, and every problem comes with samples so you can check your own program.

Four Mock Contests let you practise under a clock, and the Grand Mock Contest at the end puts the whole year together.

You should already know the Python in *Python by Projects*: variables, `if`, loops, functions, lists, dictionaries, and files.
Begin with Getting Set Up to learn how contest programs read their input and how to test them.
