# Using This Answer Key

This book gives worked answers to the odd-numbered exercises in every unit.
The answers are grouped by unit, in the same order as the exercises.

## Try first, compare after

Work on each problem before you open this book.
Run your program on every sample and on tests of your own, and fix what does not match.
If you get stuck, read just enough of the answer to spot your next step, close the book, and finish the program yourself.
When you are done, compare your program with the answer and ask why any differences matter.
Copying an answer teaches your eyes, not your hands; writing the program yourself is what builds the skill.

## A different program can be right

Most problems have many correct programs.
Your program is correct when it prints exactly the right output for every valid input within the constraints, fast enough for the largest one.
Your variable names, the order of some steps, or the way you store the data may differ from the answer shown here.
That is fine.
Still read the printed answer, because a second way to solve a problem is worth learning.

## Reading an answer

Each answer is a complete program that reads its whole input from standard input, as a contest judge runs it.
Save it in a file and run it with a sample input file, for example `python solution.py < case.txt`, then compare its output with the sample output.
A short Notice with each answer explains the key idea.

## Why only the odd-numbered exercises

The even-numbered exercises are for checking yourself.
Each one has samples and constraints, so you can tell on your own whether your program is right: if it matches every sample and stays fast on the largest input, you have solved it.
Use the odd-numbered answers to learn a method, then prove you can use it on the even-numbered exercises.

The Mock Contests and the Grand Mock Contest are not in this book for the same reason.
They measure what you can do on your own, under a clock, and their samples tell you whether you succeeded.
