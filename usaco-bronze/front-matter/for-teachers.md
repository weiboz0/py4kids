# For Teachers

This Teacher's Edition contains everything in the Student Book, plus two additions.

- **Teacher notes** open every unit and every Mock Contest: learning goals, a pacing plan, common
  mistakes, discussion prompts, differentiation, and (for the Mock Contests) timing and grading.
- **Answer keys** follow every exercise set, every Mock Contest, and the Grand Mock Contest. Each answer
  is a complete program that reads its input the way a contest judge runs it.

Every solution in this book is checked automatically against its samples and extra test cases before the
book is built, and every lesson output on the page is the output the code really prints.
