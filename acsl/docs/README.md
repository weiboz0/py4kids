# Contest Python: ACSL

A book for the American Computer Science League, in every division, organized by the contest season.
Start with the [syllabus](../syllabus.md): it lists the contest windows, the division paths and every unit.

## How to use this book

- Work through the parts in order: Foundations, then Contest 1, 2, 3 and 4.
- Study each contest's part in the weeks before that contest's window opens.
- Each item is marked with the lowest division tested on it: Elementary, Junior, Intermediate or Senior.
  Do the items marked at your division or below.
- Short-answer items ask for one exact answer.
  Programming items ask for a program that reads its input and prints the exact output.
- Try every item yourself before you open its solution.

## Running a programming solution

A programming solution is a `.py` file that reads the input with `input()` and prints the answer.
Run it from a terminal and type the input, or send a saved input file into it:

```
python solution.py < sample.in
```
