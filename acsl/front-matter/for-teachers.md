# For Teachers

This Teacher's Edition contains everything in the Student Book, plus two additions.

- **Teacher notes** open every unit and every practice paper: learning goals, a pacing plan, the division
  paths through the unit, common mistakes, discussion prompts, differentiation, and (for the practice
  papers) timing and grading in ACSL's format.
- **Answer keys** follow every exercise set and every practice paper. Short answers show the worked
  method and the one canonical answer; programming answers show a complete program that reads its input
  the way the contest does.

Every short answer in this book is checked automatically by an independent evaluator for its category, and
every program is run against its sample and extra test cases before the book is built.
