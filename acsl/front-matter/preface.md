# About This Book

This book prepares you for the American Computer Science League, a contest season of four rounds held during the school year.
Each round tests a few categories, such as number systems, recursive functions, Boolean algebra, graphs, and short programs to trace, and most divisions add one programming problem.

The book follows the season.
It opens with a Foundations unit, then gives each contest its own part, with one unit for every category on that contest, and ends each part with a timed practice paper.
Every item is marked with the lowest division that takes it, so Elementary, Junior, Intermediate and Senior students can all work from the same pages.

Most categories are solved with pencil and paper: you learn the rules exactly as the contest states them, then work examples until the answers come quickly and correctly.
For the programming problems you should already know the Python in *Python by Projects*.
Begin with Getting Set Up, then follow the path for your division in How to Use This Book.
