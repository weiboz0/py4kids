# How to Use This Book

Begin with Getting Set Up, then work through the book in order: Foundations, then the four contest parts.
Each unit opens with a problem, teaches the category's rules, and ends with exercises.

## Divisions and your path

ACSL has an Elementary, a Junior, an Intermediate and a Senior division, plus a Classroom division.
Each lesson section and exercise shows the lowest division that takes it, such as *Division: Junior and above*.
Do every item marked at your division or below, and skip the rest.

- **Elementary:** no programming. Skip Foundations, and do the Elementary sections of the Number Systems, Prefix/Infix/Postfix, Boolean Algebra and Graph Theory units; the Elementary exercises that open each of those units are your practice test for that contest.
- **Junior:** every unit except LISP, FSAs and Regular Expressions, and Assembly Language.
- **Intermediate and Senior:** every unit.
- **Classroom:** the Junior and Intermediate short-answer items; there is no programming problem.

## Following the season

The book was written for the 2026–27 season, with one part for each of the four contests.
Check the current contest dates on the ACSL website, acsl.org, and finish each part a week or two before you sit its contest.

## Reading the page

- **Program / Output:** Program shows Python code; Output shows what it prints.
- **Notice:** A short explanation of the idea the example just used.
- **Try it yourself:** A program to run; type the input it asks for, or send it a sample file.
- **Read the error:** The code is broken on purpose; use the message to find the mistake.
- **Division:** The lowest division that takes this item.
- **Challenge:** An optional stretch item; later units do not depend on it.
- **Constraints / Sample Input / Sample Output:** For a programming problem, the limits on the input and one test case with its exact output.
- **You will learn / Recap:** A short guide to the unit's goals and a reminder of what you can now do.

## Short answers

Most exercises ask for one short answer.
Work it out with pencil and paper, using exactly the rules the unit teaches.
Each answer has one correct form, and the unit shows it: for example, digits with no base subscript, capital hexadecimal digits, or a Boolean expression written as a sum of products.
On the contest, a short-answer paper is six questions in about 30 minutes, so practise until you are both correct and quick.

## Programming problems

A programming problem reads its input with `input()` and prints exactly the output described: no prompts and no extra words.
To test a program, save the sample input in a file and send it to your program:

```text
python my_solution.py < sample.txt
```

Your output must match the sample output exactly, line by line.
Then make up inputs of your own from the constraints and check those too.
