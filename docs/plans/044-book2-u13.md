## Closure discipline (preserve what each unit already teaches)

- **U13 Grids/Graphs** introduces techniques `graph-repr, bfs, dfs, flood-fill` (grid-2d from U01;
  requires recursion (U09), deque (U10), set-literal/set-ops (U04)).
  - **Adjacency list = a PLAIN dict** built with `if u not in adj: adj[u] = []` then `.append` — NO
    `defaultdict`, NO class. Undirected edges add BOTH directions.
  - **BFS = a `deque` FIFO**: `append` to enqueue, `popleft` to dequeue, `len(queue) > 0` to test — NO
    bare `.pop`. `visited` is a `set` (`{start}` literal, `.add`, `in`); `distance` is a dict; cells are
    `(r, c)` tuples.
  - **DFS / flood-fill = recursion with the `visited` set PASSED AS AN ARGUMENT** — NEVER
    `nonlocal`/`global`. Grid recursion is 4-neighbour and inputs are capped `R·C ≤ 400` (recursion
    depth safe). Base case guards bounds/`#`/already-visited BEFORE recursing.
- **All units:** pinned source-policy builtins `{len,min,max,sorted,sum,abs,round,input,print,range,
  int,str,set}`; no `.pop/.join/.index/.count/.find`, `+=`/AugAssign, chained compare (note the shipped
  code uses `0 <= nr and nr < rows`, NOT `0 <= nr < rows` — preserve that), `[x]*n`, comprehension,
  ternary `IfExp`, `del`/`global`/`nonlocal`. AST-verify after transform.

## U13 — Grids, Graphs & Traversal (introduces `graph-repr, bfs, dfs, flood-fill`; lessons:3)

Restore the unit's project hook in cell 0 (from `main`).

- **L1 — four neighbours in a grid; an adjacency-list graph.** THREE fresh rungs, each a Notice:
  (1) a grid stored as a list of strings; visit the 4 neighbours of a cell with `dr/dc` offset lists,
  guarding bounds with `0 <= nr and nr < rows`; (2) build an ADJACENCY LIST as a plain dict (undirected
  edges add both ways); (3) read a node's neighbours / degree from the dict. Then **Put it together**
  `l1.py` = the adjacency-degree solver (cell 4), `no-exec` + run line + complexity `O(E)`.
- **L2 — recursive flood-fill & breadth-first search.** THREE fresh rungs: (1) recursive FLOOD-FILL of
  a region with a `visited` set passed down, base-casing bounds/`#`/visited; (2) a `deque` FIFO — enqueue
  with `append`, dequeue with `popleft`; (3) BFS layer-by-layer recording a distance dict. Then **Put it
  together** `l2.py` = the BFS fewest-steps solver (cell 8, found-flag flat transform, keeps the deque
  import), `no-exec` + run line + complexity `O(R·C)`.
- **L3 — depth-first search reachability.** THREE fresh rungs: (1) a recursive DFS marking `visited`
  (passed as an argument); (2) follow adjacency-list neighbours, skipping visited; (3) short-circuit
  when the target is found. Then **Put it together** `l3.py` = the DFS reachability solver (cell 10,
  guard→if/else, nested `reaches` preserved), `no-exec` + run line + complexity `O(V + E)`.
- **Closure:** introduces graph-repr/bfs/dfs/flood-fill (confirm each USED); plain-dict adjacency,
  deque FIFO (no bare `.pop`), recursion with `visited` as an argument (no `nonlocal`); grids capped
  `R·C ≤ 400`.
