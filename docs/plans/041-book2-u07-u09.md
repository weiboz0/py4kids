**Contract-transform recipe (proven, plans 039/040):** read the ORIGINAL `solve()` from a pre-migration
git ref; drop `def solve`, `dedent`, convert ONLY the solver's OWN top-level `return X`→`print(X)`

`data = sys.stdin.read()`. A solver with two top-level returns (guard `if c: return A` then `return B`)
gets an explicit `if/else`; a solver that `return`s early from inside a loop gets the I/O-preserving
found-flag form. Both U07/U09 lesson solvers wrap their body in an outer `solve()` whose OWN return is
the single final one (the recursion lives in a nested helper), so they transform mechanically; verify

  base case + recursive case; try→recurse→undo. **`recursion` is scanner-detected (a self-call is

  and untaught), **no comprehension** (dropped from Book 2 — AST-checked), no lambda. The shipped U09
  solvers already avoid these (they pass `concept-scan`'s untaught-method check on `main`); the
  transform preserves them. `.append` is taught. Confirm `recursion` is USED via `detect()`.
- **All units:** pinned source-policy builtins `{len,min,max,sorted,sum,abs,round,input,print,range,
  int,str,set}`; no `+=`/AugAssign, chained compare, `[x]*n`, ternary `IfExp`, `.pop/.join/.index/

## U07 — Simulation & Ad Hoc (introduces `simulation`; lessons:2)

- **L1 — model the state, apply every rule in order.** ≥3 one-increment executable rungs, each a
  Notice: (1) parse the initial state from a literal input and print it; (2) apply ONE rule to the
  state (e.g. a capped increment `min(cap, value+delta)`) and print; (3) apply a SEQUENCE of rules in a
  loop over literal commands, printing the running state. Then **Put it together** `l1.py` = the capped
  battery-state solver (lesson cell 3), `no-exec` + run line + complexity `O(steps)`.
- **L2 — edges & provable termination.** ≥3 rungs: (1) an edge case at a boundary (clamp / wrap
  guarded); (2) a loop with an explicit stop condition that provably terminates; (3) detect a repeat /
  step cap so an ad-hoc loop cannot run forever. Then **Put it together** `l2.py` = the
  termination/edge solver (lesson cell 8), `no-exec` + run line + complexity. (Lesson cell 6, the
  edge-light automaton, becomes an L2 rung.)
- **Closure:** introduces `simulation` (technique); requires control-flow/list/dict/int/print; no new
  feature, no banned construct.

## U09 — Recursion & Backtracking (introduces `recursion, backtracking`; lessons:3)

- **L1 — a function solving a smaller copy (recursion).** ≥3 rungs: (1) **factorial** (base case
  `n==0/1` → recursive case) on a literal n (cell 2); (2) **countdown** printing during the unwinding
  to show the call stack (cell 5); (3) **recursive sum** of `1..n` accumulating through returns. Then
  **Put it together** `l1.py` = the recursive-sum stdin solver (cell 4), `no-exec` + run line +
  complexity `O(n)` depth.
- **L2 — try, recurse, undo (backtracking).** ≥3 rungs: (1) **include-or-skip subsets** counting
  those hitting a target (cell 8, `path + [value]`); (2) **permutations** choosing an unused value with
  a `used` list toggled and restored (cell 10); (3) **combinations** choosing in increasing index
  order (cell 12). Then **Put it together** `l2.py` = the subset-count stdin solver (cell 8), `no-exec`
  + run line + complexity note (exponential — small N). NO `.pop`; undo via `used[i] = False` /
  fresh `path + [value]`.
- **L3 — parsing a nested structure by recursion.** ≥3 rungs building toward recursive descent:
  (1) evaluate a single literal token; (2) evaluate one nested level; (3) recurse into arbitrary
  nesting. Then **Put it together** `l3.py` = the nested-expression evaluator (cell 14), `no-exec` +
  run line + complexity.
- **Closure:** introduces recursion (FEATURE — confirm USED via `detect()`) + backtracking (technique);
  requires control-flow/list/int/str/print; NO `.pop`, no comprehension, no lambda; recursion is legal
  here.

## Phases

### Phase A — assets (both units): stdin `.py` solvers + fixtures

For each unit build `assets/`: the pinned lesson solvers (U07 `l1`,`l2`; U09 `l1`,`l2`,`l3`) transformed
via the recipe, PLUS `ex1`–`ex9` from each shipped `solutions.ipynb`. Each solver ships **≥2
NON-VACUOUS** `.in`/`.out` fixtures from the shipped asserts + crafted witnesses. **Verify every solver
by subprocess and confirm each witness kills its mutant BEFORE commit.** Named witnesses:
- **U07** simulation: a wall/edge-DECISIVE fixture (moving the wall/edge changes the answer, so a
  wall-ignore or missing-bounds-guard mutant fails) + a termination case.
- **U09 `l1`** recursion: a base-case-decisive fixture (a wrong base case, e.g. `return 0`→`return 1`,
  changes the sum) so the base case is load-bearing.
- **U09 `l2`** backtracking: a fixture where BOTH the include and the skip branch matter (dropping the
  skip branch, or double-counting, changes the count) + a target reachable only by a specific subset.
- **U09 `l3`** recursion: a DEEPLY nested case a one-level (non-recursive) mutant gets wrong.
- AST-verify no `.pop`/comprehension/lambda/banned builtin crept in.
