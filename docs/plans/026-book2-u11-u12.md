  - base-conversion: a value whose LAST digit/bit is decisive; a boundary (0, a power of the base);
  - bitwise: a case where `&` vs `|` vs `^` differ; a FINITE-WIDTH `~` case (see below);
  - bitmask: the EMPTY mask and the FULL mask; a case where a mid subset is the unique answer;
  - gcd: coprime (→1), one divides the other, equal inputs; LCM (if used) with a shared factor;

    reduce-at-end** — instead (a) a small brute-force-checkable case pins correctness, (b) a
    WRONG-OPERAND / MISSING-FINAL-`% M` mutant is killed by a crafted case, and (c) the input sizes are
    large enough that the unreduced value is infeasible (the exec/step cap enforces reduce-as-you-go).

    differ; the graded traversal-output exercises are PRE- or POST-order (NOT in-order — in-order of a BST is
    `sorted(vals)`, which the legal `sorted` builtin would shortcut).
  **Decisive values last.**
- **`~x` finite-width rule:** Python `~x` is infinite-width two's complement (`~5 == -6`), so every NOT/

  exercises state `w`.
