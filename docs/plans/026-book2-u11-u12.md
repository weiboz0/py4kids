## Global Constraints

Copied from the design + registry + prior-gate lessons; every task's requirements include this section.
**The closure boundary SHIFTS again here — newly-legal vs still-banned below.**

- **Contract:** every reference solution is a pure `solve(data: str) -> str`; ZERO `input()` in any
  executable cell; the submission wrapper appears ONLY in a `no-exec`-tagged LESSON cell (units get the
  `kind=="unit"` cell-lint exemption) or teacher-notes; NEVER in solutions.ipynb. Deterministic. Student
  code cells are EMPTY (`''`). Every cell has an `id`.
- **NEWLY LEGAL here (do use, as the unit's teaching target):** `bitwise-ops` — `&`, `|`, `^`, `~`, `<<`,
  `>>` on ints (the FEATURE detector fires on these; it is now LISTED so it no longer reds); the TECHNIQUES
  `base-conversion`, `bitmask`, `gcd`, `sieve`, `modular-arithmetic` (U11, scanner-invisible — reviewer-
  enforced); `tree-traversal` (U12, scanner-invisible — a recursive walk over a binary tree represented as
  dicts / parallel arrays). `recursion` (U09) is now legal and is the basis of tree-traversal and Euclid/
  sieve where natural.
- **STILL BANNED (not yet taught):** NO `tree-traversal` surface in U11 (that is U12); NO `bfs`/`dfs`/
  `flood-fill`/`graph-repr` (U13 — a tree walk is fine in U12, but NO general adjacency-graph traversal); **NO
  `two-pointers` in ANY form — converging pointers OR a sliding window (U14).** **NO `.pop()`** — `.pop` is
  absent from the scanner's taught-method set, so any `.pop()` call is an untaught-method FAIL; a stack (if
  ever needed) is a `deque` using `appendleft`+`popleft` (peek `stack[0]`). **NO `comprehension`** —
  list/set/dict comps and generator expressions were DROPPED from Book 2 (plan 025); the detector is retained
  as a guard, so any comprehension reds as used-but-unlisted. Build lists with a `while`/`append` loop;
  build the sieve array with a `while`/`append` loop, **NEVER `[False]*(n+1)`** (list-repetition is
  scanner-blind and untaught). set-ops via `.add`/`.discard`/`-` only — NEVER `.remove`, `.union`/
  `.intersection`/`.difference` (note: `& | ^` are now legal as BITWISE on ints, but do NOT use them on
  sets — use a loop + `.add`). NO chained comparison `a<=b<c` (use `b>=a and b<c`). NO untaught methods
  (`.join`/`.splitlines`/`.index`/`.count`/`.find`/`.pop`). NO untaught stdlib — **NO `itertools`, NO
  `collections.Counter`, NO `math` shortcuts for the taught techniques (write Euclid/sieve yourself; no
  `math.gcd`), NO `del`.** Allowed builtins ONLY `{len,min,max,sorted,sum,abs,round}` — NO `all`/`any`/
  `enumerate`/`zip`/`reversed`/`map`/`filter`/`bin`/`hex`/`int(x,base)` shortcuts for the TAUGHT conversions
  (write base-conversion by hand; `bin()`/`hex()`/`int(s,2)` defeat `base-conversion` — ban them as the
  technique's scanner-invisible shortcut). Output assembly: `.join` is banned → build multi-item output with
  `+` string-concat. concept-scan `--book book2` clean.
- **Enforcement split:** concept-scan + ad-hoc `detect()` catch premature/mis-listed FEATURES (`bitwise-ops`
  must be LISTED in U11 introduces; no `deque`-before-use issues; no `comprehension`) + untaught methods
  (`.pop`, `.join`, …); the scanner-BLIND cases — `.remove`, banned builtins (`all`/`any`/…), chained
  comparison, list-repetition `[x]*n`, `itertools`/`Counter`/`math` imports, `del`, and the technique
  shortcuts (`bin`/`hex`/`int(x,base)`/`math.gcd`) — need an **AST check** (`ast.Compare` len(ops)>1;
  `ast.BinOp` Mult with a list operand) + **grep** (`\.pop\(`, `\bdel\b`, `itertools`, `Counter`, `\bmath\b`,
  `\bbin\(`, `\bhex\(`, `int\([^,]*,`, `all(`/`any(`/…). `tree-traversal` (U12) and the U11 techniques are
  scanner-invisible → enforce by a representation/approach audit (tree is dict/array, traversal is recursive;
  base-conversion/gcd/sieve are hand-written).
- **Two-tier `practices` (plan-020 formula):** `practices = (detected ∪ manually-listed used) − requires −
  introduces − wrapper-artifacts (file-read, import-statement)`. A concept in `requires` never also appears
  in `practices`. Earlier features used and not in requires (e.g. `str-split`) + earlier techniques used
  (`input-parse`, `complete-search`, `complexity`, `recursion`-as-feature is in U12 requires, …) + Book-1
  concepts used. `requires ∩ practices = ∅`, `practices ∩ introduces = ∅`; manifest == coverage-map exactly.
  Derive from ad-hoc `detect()`; hand-add scanner-invisible used concepts (techniques, `dict-access`).
- **Rich, laddered problem sets:** ≥ 8 `## Exercise N` per unit (tooling counts `^## Exercise \d+`), each
  with Sample Input / Sample Output / Constraints; ≥ 2 cell-tagged `stretch`. **Every output is an INTEGER
  or plain string — never a float.** Non-vacuous asserts: sample + crafted edge cases killing the technique's
  signature mutants — base-conversion: a value whose last digit/bit is decisive, a zero/boundary; bitwise: a
  case where `&` vs `|` vs `^` differ, a high-bit/`~` case; bitmask: the empty mask and the full mask, a case
  where a mid subset is the answer; gcd: coprime (→1), one divides the other, equal; sieve: a prime at the
  boundary, a composite just below a prime²; modular: a value where reducing mid-computation vs at-the-end
  differ (overflow-style), `mod` of a negative; tree-traversal: a single node, a left-only/right-only skew,
  a case where pre/in/post differ. **Decisive values last.**
- **teacher-notes:** exactly the five heading strings `## Goals`/`## Pacing`/`## Common mistakes`/
  `## Discussion prompts`/`## Differentiation`; a per-exercise Big-O line; a pacing plan covering all
  allocated lessons (U11 = 3, U12 = 2).

  `modular-arithmetic` (prereqs for CP3 and later).

- [ ] **A1 — lesson.ipynb.** Hook (e.g. "a light panel stores its state as one integer — flip switch 3
  without touching the rest"). Teach: (1) base conversion — int → binary/hex digit string and back, written
  BY HAND with `%`/`//` and digit concat (no `bin`/`hex`/`int(s,base)`); (2) bitwise ops — `&` `|` `^` `~`
  `<<` `>>`, masks, test/set/clear bit `i` (`x & (1<<i)`, `x | (1<<i)`, `x & ~(1<<i)`); (3) bitmask subset
  iteration — `for mask in range(1<<n)` + `mask & (1<<i)` to enumerate subsets; (4) gcd — Euclid
  (`while b: a, b = b, a % b`), and why; (5) sieve of Eratosthenes — boolean list built with `while`/`append`

  Runnable `solve(data)` cells; one `no-exec` wrapper cell.
- [ ] **A2 — exercises.ipynb.** ≥ 8 `## Exercise N` `solve(data)` problems that REQUIRE the techniques:
  base conversion (to/from binary or hex by hand), bit test/set/clear on a state integer, subset-sum /
  count-subsets via a bitmask over small N, GCD (and LCM via gcd), prime count / nth prime via a sieve,
  "compute X mod M" where reducing mid-way matters, a XOR-property problem (e.g. the lone unpaired value).
  ≥ 2 `stretch`. EMPTY student cells; Sample I/O + Constraints; integer/string outputs; each technique's
  decisive edge exercised (see Global Constraints); decisive value last.

  `while`/`append` (NO `[False]*(n+1)`); bitwise ops on ints; NO comprehension, NO `.pop`/`del`/`.join`/
  `itertools`/`Counter`/`math`, NO banned builtins, NO chained comparison. Non-vacuous asserts incl. each
  technique's signature edge + a decisive-last case.
- [ ] **A4 — teacher-notes.md.** Five exact headings; per-exercise Big-O (sieve O(n log log n); gcd
  O(log min); bitmask O(2ⁿ·n) — tie to small-N constraints; base-conversion O(#digits)); 3-lesson pacing
  (L1 base conversion + bitwise basics; L2 bitmask subsets + GCD; L3 sieve + modular arithmetic); common
  mistakes (off-by-one in bit index; `[False]*n` habit; forgetting to reduce mod mid-computation; sieve
  bounds; `~x` two's-complement sign surprise → mask it).
- [ ] **A5 — manifest.yaml + map.** `introduces: [bitwise-ops, base-conversion, bitmask, gcd, sieve,

  integer/string outputs (traversal sequences built with `+` concat — `.join` banned); single-node,
  skewed-tree, and pre≠in≠post cases exercised; decisive value last.

  BFS/DFS surface (a BINARY-TREE recursive walk only). Non-vacuous asserts incl. single node, a left-only/
  right-only skew, and a pre/in/post-distinguishing tree.
- [ ] **B4 — teacher-notes.md.** Five exact headings; per-exercise Big-O (O(N) traversals; O(height) BST
  search); 2-lesson pacing (L1 tree representation + traversals; L2 BST search/insert + validation); common

- [ ] **B5 — manifest.yaml + map.** `introduces: [tree-traversal]`; `requires:` trimmed (incl. `recursion`,
