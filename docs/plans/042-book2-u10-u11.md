## Closure discipline (preserve what each unit already teaches)

- **U10 Stacks/Queues/Deques** introduces FEATURE `deque` + technique `postfix-eval`. Stack/queue via
  `deque()`: push `appendleft`, pop `popleft`, enqueue `append`, peek `stack[0]`, empty `len(stack)==0`
  — **NO bare `.pop`** (banned by source-policy; `.popleft`/`.appendleft` are the taught deque methods
  and are NOT banned), **no `.join`** (build strings with a loop). `from collections import deque` is
  the one allowed import.
- **U11 Number Systems/Bitwise/Number Theory** introduces FEATURE `bitwise-ops` + techniques
  `base-conversion, bitmask, gcd, sieve, modular-arithmetic`. **Bitwise operators `& | ^ << >>` are
  LEGAL here** (introduced this unit). **RECURSION-FREE** (recursion is untaught-here → a self-call
  REDs concept-scan; use `while`/`for`). Base conversion by hand with `% base` / `// base` loops —
  **NO `bin()`/`hex()`/`oct()`/`format()`/`int(x, base)`/f-string base specs (`:b`/`:x`)/`0b`/`0x`/`0o`
  literals/3-arg `pow(a,b,m)`/`divmod`/`from math import`/`.bit_length`/`.bit_count`** (all
  scanner-blind — reviewer/AST-grep enforced). `+=` is untaught (`x = x + 1`). Integer truthiness: the
  shipped lesson TEACHES "a nonzero int is True" (so `while n:` is taught here) — preserve that; in any
  NEWLY-authored rung prefer `!= 0` to stay unambiguous.
- **All units:** pinned source-policy builtins `{len,min,max,sorted,sum,abs,round,input,print,range,
  int,str,set}`; no comprehension/ternary `IfExp`/`[x]*n`/chained compare/`del`/`global`/`nonlocal`.
  AST-verify after transform.

## U10 — Stacks, Queues & Deques (introduces `deque, postfix-eval`; lessons:2)

Restore the unit's project hook in cell 0 (from `main` — the batch-3 lesson: do NOT genericize it).

- **L1 — LIFO stacks & FIFO queues.** THREE fresh one-increment rungs, each a Notice: (1) a STACK with
  `deque` — `appendleft` to push, `stack[0]` to peek, `popleft` to pop — on literal data; (2) a QUEUE —
  `append` to enqueue, `popleft` to dequeue, `len(q)==0` to test empty; (3) match one pair of brackets
  with a stack (push openers, pop on a closer, check the match). Then **Put it together** `l1.py` = the
  bracket-matching solver (lesson cell 7, found-flag flat transform), `no-exec` + run line + complexity
  `O(n)`.
- **L2 — evaluate postfix & monotonic stack.** THREE fresh rungs: (1) push numbers, on an operator pop
  two and push the result; (2) evaluate a short literal postfix expression end-to-end; (3) a monotonic
  stack "next greater" pass on literal data. Then **Put it together** `l2.py` = the postfix-evaluator
  solver (cell 9), `no-exec` + run line + complexity `O(n)`.
- **Closure:** introduces deque/postfix-eval; deque ops only (no bare `.pop`/`.join`); requires
  control-flow/list/int/str/print.

## U11 — Number Systems, Bitwise & Number Theory (introduces `bitwise-ops, base-conversion, bitmask, gcd, sieve, modular-arithmetic`; lessons:3)

Restore the project hook in cell 0 (from `main`).

- **L1 — binary/hex & bits.** THREE fresh rungs: (1) decimal→binary by repeated `% 2` / `// 2` into a
  digit string (no `bin()`); (2) binary→decimal by a place-value loop; (3) store switches as bits and
  read/set one with `& (1 << k)` / `| (1 << k)` (bitwise legal here) — and NOT within a finite width
  via `mask ^ x`. Then **Put it together** `l1.py` = the base-conversion solver (cell 3),
  `no-exec` + run line + complexity.
- **L2 — bitmask subsets, GCD & LCM.** THREE fresh rungs: (1) enumerate subsets by iterating masks
  `0..(1<<n)-1` and testing bit `mask & (1 << i)`; (2) Euclid's GCD by `while`; (3) LCM via
  `a // gcd * b`. Then **Put it together** `l2.py` = the exact-subset (bitmask) solver (cell 8),
  `no-exec` + run line + complexity `O(2^n · n)`.
- **L3 — sieve & modular reduce-as-you-go.** THREE fresh rungs: (1) mark composites in a boolean list
  up to N (sieve); (2) collect the primes; (3) reduce a running product/power `% m` each step so it
  never grows large. Then **Put it together** `l3.py` = the sieve prime-count solver (cell 12),
  `no-exec` + run line + complexity `O(N log log N)`.
- **Closure:** introduces the six concepts (confirm `bitwise-ops` USED via `detect()`); bitwise
  operators legal; NO recursion, NO `bin/hex/oct/format/int(x,base)/pow(a,b,m)/divmod/.bit_length`, no
  `+=`; integer-truthiness taught by the lesson (preserve), `!= 0` in new rungs.
