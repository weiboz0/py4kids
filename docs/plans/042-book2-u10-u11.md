- **U10 Stacks/Queues/Deques** introduces FEATURE `deque` + technique `postfix-eval`. Stack/queue via

  — **NO bare `.pop`** (banned by source-policy; `.popleft`/`.appendleft` are the taught deque methods
  and are NOT banned), **no `.join`** (build strings with a loop). `from collections import deque` is
  the one allowed import.
- **U11 Number Systems/Bitwise/Number Theory** introduces FEATURE `bitwise-ops` + techniques
  `base-conversion, bitmask, gcd, sieve, modular-arithmetic`. **Bitwise operators `& | ^ << >> ~` are
  LEGAL here** (introduced this unit — including `~`, which the shipped lesson's "NOT needs a finite
  width" cells teach and ex3/ex9 use as `~x & ((1 << W) - 1)`). **RECURSION-FREE** (recursion is
  untaught-here → a self-call REDs concept-scan; use `while`/`for`). Base conversion by hand with
  `% base` / `// base` loops — **NO `bin()`/`hex()`/`oct()`/`format()`/`int(x, base)`/f-string base
  specs (`:b`/`:x`)/`0b`/`0x`/`0o` literals/3-arg `pow(a,b,m)`/`divmod`/`from math import`/`.bit_length`/
  `.bit_count`** (`bin/hex/oct/format/pow/divmod` are caught by `source-policy`'s builtin allowlist and
  `.bit_length`/`.bit_count` by `concept-scan`'s unknown-method path; the **truly scanner-blind** set is
  `int(x, base)`, the `0b`/`0x`/`0o` literals, f-string base specs (`:b`/`:x`), and `from math import` —

## U11 — Number Systems, Bitwise & Number Theory (introduces `bitwise-ops, base-conversion, bitmask, gcd, sieve, modular-arithmetic`; lessons:3)

Restore the project hook in cell 0 (from `main`).

- **L1 — binary/hex & bits.** THREE fresh rungs: (1) decimal→binary by repeated `% 2` / `// 2` into a
  digit string (no `bin()`); (2) binary→decimal by a place-value loop; (3) store switches as bits and
  read/set one with `& (1 << k)` / `| (1 << k)` (bitwise legal here), and complement within a FINITE
  WIDTH with `~x & ((1 << w) - 1)` — the exact idiom ex3/ex9 require and the lesson's "NOT needs a
  finite width" cells teach (show `state & (full_mask ^ bit)` as the single-bit-clear equivalent).
  Then **Put it together** `l1.py` = the base-conversion solver (cell 3),
  `no-exec` + run line + complexity.
- **L2 — bitmask subsets, GCD & LCM.** THREE fresh rungs: (1) enumerate subsets by iterating masks
  `0..(1<<n)-1` and testing bit `mask & (1 << i)`; (2) Euclid's GCD by `while`; (3) LCM via
  `a // gcd * b`. Then **Put it together** `l2.py` = the exact-subset (bitmask) solver (cell 8),
  `no-exec` + run line + complexity `O(2^n · n)`.
- **L3 — sieve & modular reduce-as-you-go.** THREE fresh rungs: (1) mark composites in a boolean list
  up to N (sieve); (2) collect the primes; (3) reduce a running product/power `% m` each step so it
  never grows large. Then **Put it together** `l3.py` = the sieve prime-count solver (cell 12),
  `no-exec` + run line + complexity `O(N log log N)`.
- **Closure:** introduces the six concepts (confirm `bitwise-ops` USED via `detect()`); bitwise
  operators legal; NO recursion, NO `bin/hex/oct/format/int(x,base)/pow(a,b,m)/divmod/.bit_length`, no
  `+=`; integer-truthiness taught by the lesson (preserve), `!= 0` in new rungs.
