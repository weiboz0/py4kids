# Plan 025 — Book 2 U09 "Recursion & Backtracking" + U10 "Stacks, Queues & Deques"

**Goal:** Ship the first two Term-3 units — `unit-09-recursion-backtracking` (introduces the FEATURES
`recursion`, `comprehension` + the TECHNIQUE `backtracking`) and `unit-10-stacks-queues-deques` (introduces
the FEATURE `deque` + the TECHNIQUE `postfix-eval`) — on the `solve(data:str)->str` contract, following the
established Book-2 unit pattern.

**Architecture:** Two units, each the standard Book-2 set (lesson/exercises/solutions/teacher-notes/
manifest). **This plan is where several previously-banned features become legal:** U09 introduces
`recursion` (a named self-calling function) and `comprehension` (list/set/dict comps), plus the
reviewer-enforced technique `backtracking` (try → recurse → undo — subset/permutation GENERATION, which
was deferred here from U05); U10 introduces `deque` (`from collections import deque`, `appendleft`/`popleft`)
plus the technique `postfix-eval` (evaluate RPN with a stack). Graded exercises REQUIRE the technique (a
genuine recursion / backtracking search; a stack/queue/deque computation). Wire each into ci-local via the
existing Book-2 per-entry block.

**Tech Stack:** Jupyter notebooks (nbformat), `tools/` checks, `scripts/ci-local.sh`,
`py4kids-tools --book book2`; Python 3 stdlib only (`collections.deque` for U10).

**Spec:** `docs/designs/001-book2-algorithms.md` (§4/§5/§7 — U09 "base/recursive case; permutations/subsets;
try→recurse→undo", U10 "LIFO/FIFO, deque, bracket matching, postfix evaluation"); `book2/syllabus.md`;
`book2/curriculum/coverage-map.yaml` (U09/U10 entries); `tools/concept_scan.py` (the recursion/comprehension/
deque detectors — verified below); plans 018–024 (the shipped pattern + all closure/gate lessons).

## Global Constraints

Copied from the design + registry + prior-gate lessons; every task's requirements include this section.
**The closure boundary SHIFTS at this point in the arc — newly-legal vs still-banned below.**

- **Contract:** every reference solution is a pure `solve(data: str) -> str`; ZERO `input()` in any
  executable cell; the submission wrapper appears ONLY in a `no-exec`-tagged LESSON cell (units get the
  `kind=="unit"` cell-lint exemption) or teacher-notes; NEVER in solutions.ipynb. Deterministic. Student
  code cells are EMPTY (`''`). Every cell has an `id`.
- **NEWLY LEGAL here (do use, as the unit's teaching target):** `recursion` — a NAMED function that calls
  itself (the detector fires on a `FunctionDef` whose body contains a Call to its own name; NO `lambda`);
  `comprehension` — list/set/dict comprehensions and generator expressions (U09+); `backtracking` (U09,
  technique); `deque` — `from collections import deque`, `.appendleft`, `.popleft` (U10+); `postfix-eval`
  (U10, technique). **A comprehension may now be used, BUT still NOT inside a banned builtin** (see below).
- **STILL BANNED (not yet taught): NO `.pop()`** — `.pop` is absent from the scanner's taught-method set
  (`TAUGHT_METHODS` + the book2 profile admit string/dict/file/list `append`/`sort` and, because `deque` is
  registered whole-book, `appendleft`/`popleft` — but NEVER `pop`), so any `.pop()` call becomes an
  untaught-method FAIL. **A STACK is a `deque` using `appendleft`+`popleft`; a QUEUE is a `deque` using
  `append`+`popleft` — never `.pop()`.** NO bitwise-ops `&|^`/shifts / `base-conversion` / `bitmask` / `gcd`
  / `sieve` / `modular-arithmetic` (U11 — and plain `%` is Book-1 arithmetic, NOT the modular-arithmetic
  technique: no modular identities/inverses/"answer mod p" framing); NO `tree-traversal` (U12 — so NO
  recursive walk over a binary-tree/BST node representation; expression evaluation must be over a flat/
  nested-parenthesized string, not a tree); NO `bfs`/`dfs`/`flood-fill`/`graph-repr` (U13); **NO
  `two-pointers` in ANY form — converging pointers OR a sliding window (U14).** set-ops via `.add`/`.discard`/
  `-` only — NEVER `.remove`, `&|^`, `.union`/`.intersection`/`.difference`. NO chained comparison `a<=b<c`
  (never taught → use `b>=a and b<c`). NO untaught methods (.join/.splitlines/.index/.count/.find/.pop). NO
  untaught stdlib shortcuts — **NO `itertools` (permutations/combinations/product — they scanner-invisibly
  defeat U09's recursion/backtracking requirement), NO `collections.Counter`, NO `del` statement** (an
  invisible undo now that `.pop` is banned). Allowed builtins ONLY `{len,min,max,sorted,sum,abs,round}` — NO
  `all`/`any`/`enumerate`/`zip`/`reversed`/`map`/`filter` (so NO genexp inside `all()`/`any()`). Output
  assembly: `.join` is banned → build multi-item output with `+` string-concat, or prefer count / single-
  string answers. concept-scan `--book book2` clean.
- **Enforcement split:** concept-scan + ad-hoc `detect()` catch premature FEATURES (bitwise-ops,
  tree-traversal, deque before U10, etc.) + untaught methods (`.pop`, `.join`, …); the scanner-BLIND cases
  — `.remove`, the banned builtins (`all`/`any`/…), chained comparison, list-repetition, **`itertools`/
  `collections.Counter` imports, and `del`** — need an **AST check** (`ast.Compare` len(ops)>1; `ast.BinOp`
  Mult with a list operand) + **grep** (`\.pop\(`, `\bdel\b`, `itertools`, `Counter`, `all(`/`any(`/…).
  Recursion depth bounded by the input (no runaway); the backtracking UNDO is pop-free and MUST NOT rely on
  rebinding — use EITHER an immutable extended copy passed down (`recurse(path + [choice])`, leaving the
  caller's `path` untouched — safest) OR an in-place slice restore (`path[:] = path[:-1]`). **NEVER
  `path = path[:-1]`** (that rebinds only the local name and leaves the shared list mutated in the caller),
  and NEVER `del`/`.pop`. mutation/exec runs cap steps.
- **Two-tier `practices` (plan-020 formula):** `practices = (detected ∪ manually-listed used) − requires −
  introduces − wrapper-artifacts (file-read, import-statement)`. A concept in `requires` never also appears
  in `practices`. `str-split` (feature, if used and not in requires) + earlier techniques used
  (`input-parse`, `complete-search`, `complexity`, …, if not in requires) + Book-1 concepts used.
  `requires ∩ practices = ∅`, `practices ∩ introduces = ∅`; manifest == coverage-map exactly. Derive from
  ad-hoc `detect()`; hand-add scanner-invisible used concepts (techniques, `dict-access`).
- **Rich, laddered problem sets:** ≥ 8 `## Exercise N` per unit (tooling counts `^## Exercise \d+`), each
  with Sample Input / Sample Output / Constraints; ≥ 2 cell-tagged `stretch`. **Every output is an INTEGER
  or plain string — never a float.** Non-vacuous asserts: sample + crafted edge cases killing the technique's
  signature mutants — recursion/backtracking: the base case (empty / N=0 / no solution → the correct empty
  answer), a case needing the try→undo (a partial path that must be abandoned), a decisive-last choice;
  deque/postfix: the LIFO/FIFO order (a case where stack vs queue differ), an empty-stack / unbalanced edge,
  a decisive-last token. Decisive values last.
- **teacher-notes:** exactly the five heading strings `## Goals`/`## Pacing`/`## Common mistakes`/
  `## Discussion prompts`/`## Differentiation`; a per-exercise Big-O line; a pacing plan covering all
  allocated lessons (U09 = 3, U10 = 2).
